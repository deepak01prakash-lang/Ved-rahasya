# Ved Rahasya — Flutter starter

This is the first runnable cross-platform starter for the Ved Rahasya app.

## Included
- Android and iOS Flutter project structure
- Saffron and gold visual theme
- Hindi / Sanskrit / English language selector
- Home screen with Bhagavad Gita 2.47
- Veda, Gita, Upanishad, mantra and meditation sections
- Working mantra counter
- In-memory bookmark toggle

## Run
1. Install Flutter SDK and Android Studio / Xcode.
2. Extract this folder.
3. Run `flutter pub get`
4. Run `flutter run`

For iOS builds, use macOS with Xcode. This starter has not been compiled or signed into an APK/IPA in this environment.
